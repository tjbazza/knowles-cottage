# Knowles Cottage website

A static HTML website for Knowles Cottage, Gargrave.

## Local preview
Open `index.html` in a browser, or run any simple static web server from this folder.

## GitHub + Netlify
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In Netlify, choose **Add new project → Import an existing project → GitHub**.
4. Select the repository. No build command is required; the publish directory is `.`.
5. Deploy.

All images are stored locally in `assets/images/`, so no image hosting service is required.
